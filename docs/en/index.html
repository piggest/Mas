Mas

Scoop up your screen.
Precise, effortless screenshots for Mac.

Download Open User Guide
v5.1.0 — macOS 13.0+

Install with Homebrew

Two lines in Terminal and you're done.

brew tap piggest/mas
brew install --cask mas

Three steps. That's it.

1

Double-click

Double-click the Mas icon in the menu bar to enter region selection mode.

2

Select a region

Drag to select the area you want. The selection is cropped instantly.

3

Add annotations

Arrows, text, blur, and more — annotate right away with a rich set of editing tools.

Features

📸

Flexible capture

Full screen, region, window, or capture frame. Shoot fast with keyboard shortcuts. Remembers your last region too.

✏️

Rich editing tools

Arrows, rectangles, ellipses, text, pen, marker, mosaic. Every tool you need, all in one place.

🔍

Text recognition (OCR)

Recognizes text inside screenshots. Select and copy character by character. Japanese and English supported.

✂️

Crop

Trim away what you don't need. Adjust the region right after capture.

🎬

GIF recording

Record any screen area as an animated GIF. Perfect for sharing how-tos and bug reports.

🎥

Video capture

Record a screen region to MP4. Trim or export to GIF too. Great for documenting workflows.

📋

Drag & drop

Drag the edited image straight into another app. Annotated images, ready to use.

📂

Library

Browse capture history with thumbnails. Favorite, filter, and find anything in seconds.
