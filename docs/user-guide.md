# Mas ユーザーガイド

<p align="center">まるでマスですくうように<br>簡単に正確にスクリーンショットを作成します</p>

**Mas**（Mac Area Screenshot）は、macOS向けのスクリーンショット撮影・編集アプリです。
キャプチャ、アノテーション、GIF/動画録画、テキスト認識、自動撮影など、スクリーンショットに必要な機能をコンパクトにまとめています。

---

## インストール

### Homebrew（推奨）

```bash
brew tap piggest/mas
brew install --cask mas
```

### 手動インストール

1. [Releases](https://github.com/piggest/Mas/releases) から最新の `Mas-x.x.x.dmg` をダウンロード
2. DMG を開いて `Mas.app` を `/Applications` フォルダに移動
3. 初回起動時に画面収録の権限を許可

### システム要件

- macOS 13.0（Ventura）以上
- 画面収録の権限

---

## はじめに

Mas はメニューバーに常駐するアプリです。

**一番シンプルな使い方：メニューバーの Mas アイコンをダブルクリック**するだけ。

1. ダブルクリックすると範囲選択モードに入ります
2. ドラッグで撮りたい範囲を選択すると、そのまま切り取られます
3. エディターウィンドウが開くので、必要に応じて編集ツールで注釈を入れられます

## キャプチャ

各キャプチャ方法と既定のショートカット。

| 方法 | 操作 | ショートカット |
|------|------|--------------|
| 全画面 | メニュー →「全画面」 | `⌘⇧3` |
| 範囲選択 | メニュー →「範囲選択」またはアイコンをダブルクリック | `⌘⇧4` |
| キャプチャ枠 | メニュー →「キャプチャ枠を表示」 | `⌘⇧6` |
| GIF録画 | メニュー →「GIF録画」 | `⌘⇧7` |
| 動画撮影 | メニュー →「動画撮影」 | `⌘⇧8` |
| 画像を開く | メニュー →「開く...」 | `⌘O` |

キャプチャ後は自動的にエディターウィンドウが開きます。

![メニュー](../images/menu.png)

### 全画面

`⌘⇧3` でメインディスプレイ全体をキャプチャします。

### 範囲選択

1. `⌘⇧4` を押すと画面全体にオーバーレイが表示されます
2. マウスをドラッグして範囲を選択
3. マウスを離すとキャプチャが実行されます
4. `ESC` キーでキャンセル

前回選択した範囲は記憶されており、`⌘⇧6` のキャプチャ枠で再利用できます。

### キャプチャ枠

`⌘⇧6` で前回の範囲を枠として表示します。サイズと位置を調整してから撮影できるので、UI 要素を毎回同じ範囲で撮りたいときに便利です。

- ウィンドウ位置は閉じた時点で記憶され、次回も同じ場所に復元されます
- 枠から再キャプチャ・GIF録画・動画録画への切り替えも可能（右上のアクションボタン）

### GIF録画

画面の指定領域をアニメーション GIF として録画します。

**手順:**

1. `⌘⇧7` を押すと範囲選択モードに入ります
2. ドラッグで録画範囲を選択すると、すぐに録画が開始されます
3. 録画範囲に赤い枠線が表示され、上部にコントロールパネルが現れます
4. 停止ボタンを押すと GIF ファイルが生成されます

**録画仕様:**

- フレームレート: 10 FPS
- 形式: アニメーション GIF（無限ループ）
- 保存先: 自動保存フォルダ（設定時）または `~/Pictures/Mas`

#### GIFプレイヤー

録画完了後、GIF はエディターウィンドウで開かれます。下部のフローティングツールバーで再生操作が可能です。

| 操作 | 説明 |
|------|------|
| 再生/一時停止 | プレビュー再生・停止 |
| 前/次フレーム | 1 フレーム単位で移動 |
| フレームスライダー | 任意のフレーム位置にシーク |
| 再生速度 | 0.5x / 1x / 2x |

> 録画コントロールウィンドウ（赤枠・停止ボタン）は GIF に写り込みません。

### 動画撮影

画面の指定領域を MP4 形式の動画として録画します。

**手順:**

1. `⌘⇧8` を押すと範囲選択モードに入ります
2. ドラッグで録画範囲を選択すると、すぐに録画が開始されます
3. 停止ボタンを押すと動画ファイルが生成されます

**録画仕様:**

- フレームレート: 20 FPS
- 形式: MP4（H.264）
- 音声: 設定で「動画録画時にシステム音声を録音」が ON のときシステム音声を含める
- 保存先: 自動保存フォルダ（設定時）または `~/Pictures/Mas`

#### ビデオプレイヤー

| 操作 | 説明 |
|------|------|
| 再生/一時停止 | プレビュー再生・停止 |
| 5 秒戻し / 5 秒進み | 前後にジャンプ |
| 前/次フレーム | 1 フレーム単位で移動 |
| フレームスライダー | 任意の位置にシーク |
| 再生速度 | 0.5x / 1x / 2x |

#### 動画のトリミング

ツールバーの「トリム」ボタンから範囲を切り出せます。

1. 「トリム」をクリック
2. スライダーで開始位置と終了位置を設定
3. 「確定」で指定範囲を切り出した新しい動画ファイルが生成されます

#### 動画から GIF へエクスポート

ビデオプレイヤーのツールバーから「GIF」ボタンで GIF に変換できます。トリム中の場合はトリム範囲のみ、そうでなければ動画全体が対象です。

### 画像を開く

`⌘O` で既存の画像ファイル（PNG / JPEG / GIF / MP4 等）をエディターで開けます。

### マルチディスプレイ

複数ディスプレイ環境にも対応しています。各ディスプレイを個別にキャプチャでき、範囲選択はディスプレイをまたいで指定可能です。

## 編集（アノテーション）

エディターのフローティングツールバーから各種ツールを使えます。

### 編集モードの開始

エディターウィンドウ左下の鉛筆アイコン（✏️）、または **ウィンドウを右クリック → 編集モード切替** で編集を開始できます。

### 移動

<img src="../images/tools/move.png" width="20"> アノテーションをクリックして選択、ドラッグで移動・ハンドルでリサイズ。

### ペン / マーカー

| ツール | アイコン | 説明 |
|--------|:-------:|------|
| ペン | <img src="../images/tools/pen.png" width="20"> | 自由に線を描画 |
| マーカー | <img src="../images/tools/marker.png" width="20"> | 半透明のハイライトを描画（太さ 3 倍） |

### 直線 / 矢印 / 矢印文字

| ツール | 説明 |
|--------|------|
| 直線 | 矢頭のないシンプルな直線。始点・終点ハンドルでリサイズ可能 |
| 矢印 | テーパー形状の矢印。尻尾が細く、先端に向かって太くなる |
| 矢印文字 | 矢印 + 引き出しテキスト。指示書きやコメント付き矢印に最適 |

### 四角 / 丸

四角形・楕円を描画。枠線のみ／半透明塗りつぶしを切り替え可能。

### 文字

<img src="../images/tools/text.png" width="20"> テキストを画像上に配置。クリックして配置 → キーボード入力。

### ぼかし（モザイク）

<img src="../images/tools/mosaic.png" width="20"> 矩形領域にピクセル化（モザイク）効果を適用。個人情報や機密情報のマスキングに使えます。

### トリミング

<img src="../images/tools/trim.png" width="20"> 画像の一部を切り出します。

1. ツールバーから「トリミング」を選択
2. ドラッグで切り出し範囲を決定
3. 確定ボタンで適用

### テキスト選択（OCR）

<img src="../images/tools/ocr.png" width="20"> スクリーンショット内のテキストを認識し、文字単位で選択・コピーできます。

1. ツールバーから「テキスト選択」（虫眼鏡アイコン）を選択
2. テキスト領域が自動でハイライトされます
3. ドラッグで**文字単位**で選択
4. `⌘C` でクリップボードにコピー

VisionKit の Live Text を使用しており、日本語（縦書き含む）/ 英語の混在テキスト・表組み・丸数字・手書きを認識します。

### 共通オプション

- **色** — パレットから 10 色を選択（赤、橙、黄、緑、青、紫、ピンク、黒、白、グレー）
- **太さ** — スライダーで調整（1〜10 pt）。ドラッグ中もリアルタイム反映
- **縁取り** — トグルで切り替え。3 段階描画（黒い外縁 → 白い境界線 → 元の色）でどんな背景でも視認性確保
- **塗りつぶし** — 四角・丸で半透明の塗りつぶしを切替
- **Undo** — Undo ボタンで最大 50 段階まで取り消し
- **削除** — 選択中に `Delete` キー、またはツールバーの削除ボタン

### ツールグループ

ボタンクリックでグループ内の選択メニューが開きます。最後に選択したツールが記憶されるので素速く切り替えられます。

| グループ | 含まれるツール |
|----------|----------------|
| 描画 | ペン / マーカー |
| 図形 | 直線 / 矢印 / 矢印文字 / 四角 / 丸 |

## エディターウィンドウ

キャプチャ後に表示されるウィンドウです。

### ボタン構成

#### 左上

| ボタン | 説明 |
|--------|------|
| 閉じる (×) | ウィンドウを閉じる |
| ピン (📌) | ウィンドウを最前面に固定/解除 |

#### 右上

| ボタン | 条件 | 説明 |
|--------|------|------|
| パススルー (👆) | 枠のみ表示時 | マウスイベントを背面のアプリに透過 |
| キャプチャアクション | キャプチャ範囲あり | 再キャプチャ / GIF録画 / 動画録画（右クリックでモード切替） |

キャプチャアクションボタンは撮影モードに応じてアイコンが自動切替されます（スクショ→📷、GIF→⏺、動画→🎥）。

#### 下部

| ボタン | 説明 |
|--------|------|
| 編集モード (✏️) | 左下。クリックで編集モードの ON/OFF |
| ドラッグ (↗) | 右下。ファイルとして他のアプリにドラッグ&ドロップ |

### 基本操作

| 操作 | 動作 |
|------|------|
| ダブルクリック | 画像を非表示にして枠のみ表示（もう一度で戻す） |
| 右クリック | コンテキストメニュー（閉じる・コピー・編集モード切替・シャッター） |

### パススルーモード

エディターウィンドウをダブルクリックすると、画像が非表示になり枠のみが残ります。この状態で右上の「パススルー」ボタンをクリックすると、マウスイベントがウィンドウを透過して背面のアプリに届くようになります。キャプチャ範囲の位置をガイドとして残しつつ、背面のアプリを操作できます。

### 自動拡張

アノテーションが画像端からはみ出すと、エディターウィンドウが自動拡張されます。コンテンツは元の画面位置に固定されたまま、はみ出し方向にウィンドウが伸びます（拡張のみ・縮小はしない）。
画面に収まりきらない場合はコンテンツ側を自動縮小して常に全体を表示します。

### エディターショートカット

| ショートカット | 機能 |
|--------------|------|
| `⌘S` | 画像を保存 |
| `⌘C` | 画像をクリップボードにコピー |
| `⌘Z` | 操作を取り消し |
| `Delete` / `Backspace` | 選択中のアノテーションを削除 |

## シャッター（自動撮影）

時間や条件をトリガーに自動でキャプチャを実行する機能です。4 種類のモードがあります。

### シャッターの起動

エディターウィンドウを右クリック →「シャッター」から起動します。シャッターパネルはエディターウィンドウの右側に表示され、ウィンドウの移動に追従します。

> 使うには、まずキャプチャ枠（`⌘⇧6`）や範囲選択でエディターウィンドウを表示しておく必要があります。

シャッターパネル上部のタブで 4 つのモードを切り替えできます。

### 時限モード（遅延キャプチャ）

指定した秒数後に自動でキャプチャを実行。右クリックメニューの撮影など、操作中の UI をキャプチャしたい場合に便利です。

1. 「時限」タブを選択
2. 遅延秒数を設定（1〜30 秒、スライダー）
3. 「開始」をクリック → カウントダウン後にキャプチャ

### インターバルモード（定期撮影）

一定間隔で自動的に連続キャプチャを実行。変化の記録や定点観測向け。

1. 「インターバル」タブを選択
2. 撮影間隔（0.5〜60 秒、スライダー）と最大枚数（0〜1000、0=無制限）を設定
3. 「開始」をクリック
4. 手動停止または最大枚数で自動停止

### 変化検知モード

画面の指定領域を監視し、変化を検知した時に自動でキャプチャ。ダイアログの出現や UI 状態の変化を撮り逃さない機能です。

1. 「変化検知」タブを選択
2. 検知感度を調整（0.1〜100%、小さいほど敏感）
3. 必要に応じて監視サブ領域を指定（指定しない場合はキャプチャ範囲全体）
4. 「開始」をクリック → 監視対象の画面が変化するとキャプチャ
5. 変化率はリアルタイムで表示

### プログラマブルモード

複数のステップを組み合わせて、自動キャプチャシーケンスを構築できます。最も柔軟なモードです。

#### ステップの種類

| ステップ | 説明 | パラメータ |
|---------|------|-----------|
| 撮影 | キャプチャを実行 | — |
| 待機 | 指定秒数待機 | 秒数 |
| 変化待ち | 監視領域の変化を検知するまで待機 | 感度（既定 5%） |
| 安定待ち | 画面が安定（変化が感度以下）になるまで待機 | 感度 |
| 繰り返し | 子ステップを指定回数ループ | 回数（0=無限）、子ステップ |

#### 操作方法

1. 「＋」ボタンでステップを追加
2. 各ステップのパラメータを設定（インラインステッパーで数値入力）
3. ドラッグ&ドロップでステップの順序を変更
4. 「開始」をクリックしてシーケンスを実行

実行中ステップはシアン枠で強調表示されます。ループブロックは緑、変化待ちは紫に色分け。

#### プログラムの保存と読み込み

- **保存**: プログラム名を入力して保存ボタン
- **読み込み**: 保存済みプログラムの一覧から選択
- **最後のステップ**: 最後に実行したステップ構成は自動的に記憶

#### ステップ別監視範囲の指定

変化待ち・安定待ちステップでは、監視する領域をステップごとに個別に指定できます。

1. ステップの監視領域ボタンをクリック
2. エディターウィンドウ上でドラッグして監視範囲を選択
3. 設定済みの領域は破線で常時表示、選択中ステップは太枠でハイライト
4. 👁 アイコンで監視範囲の表示/非表示をトグル
5. 右クリックメニューから領域の再選択・リセット

監視領域を指定しない場合は、キャプチャ範囲全体が監視対象になります。
変化待ち・安定待ちは「前回の撮影ステップ」の画像を基準に比較します。

## ライブラリ

キャプチャ履歴を管理するウィンドウです。メニューから「ライブラリ」を選択するか、`⌘⇧L` で開きます。

![ライブラリ](../images/library.png)

### 表示と操作

- サムネイル付きでキャプチャ履歴をグリッド表示
- クリックでエディターウィンドウを開閉
- アノテーション付きの履歴にはラベル表示
- 件数表示（右上）と保存フォルダを開くボタン

### お気に入り

- 各エントリの星アイコンでお気に入り登録
- ヘッダーの星ボタン（「すべて」⇔「お気に入り」）でフィルタリング

### カテゴリ

エントリにカテゴリ（タグ）を設定して整理できます。

- ヘッダーのタグアイコンでカテゴリフィルター
- 右クリックメニュー or 一括操作からカテゴリを設定
- 未分類のエントリは「未分類」フィルタで絞り込み

### 複数選択と一括削除

- `⌘` / `⇧` キーで複数選択
- 選択数を表示し、選択解除ボタンで全解除
- 選択アイテムの一括削除（確認ダイアログあり）
- 選択アイテムへの一括カテゴリ設定

## 設定

メニューの「設定...」（`⌘,`）から設定ウィンドウを開けます。5 つのタブで構成されています。

![設定](../images/settings.png)

### 一般タブ

#### キャプチャ

| 設定項目 | 説明 |
|---------|------|
| クリップボードにコピー | キャプチャ後に自動コピー |
| ファイルに保存 | キャプチャ後に自動保存 |
| 保存先 | 保存先フォルダの指定（「変更...」で選択） |
| 保存形式 | PNG / JPEG |
| JPEG品質 | 10〜100% で調整（JPEG 選択時に表示） |

#### その他

| 設定項目 | 説明 |
|---------|------|
| マウスカーソルを含める | キャプチャにカーソルを含める |
| キャプチャ時にサウンド再生 | キャプチャ時にサウンドを再生 |
| 動画録画時にシステム音声を録音 | 動画撮影時にシステム音声を含める |
| ログイン時に起動 | ログイン時に Mas を自動起動 |
| 開発者モード | ON にすると「開発」タブが表示される |

#### アップデート

| 設定項目 | 説明 |
|---------|------|
| 自動アップデート | GitHub Releases から最新版を自動検出・インストール |
| 今すぐ確認 | 手動で更新チェック（状態表示付き） |

### 表示タブ

#### ウィンドウ

| 設定項目 | 説明 |
|---------|------|
| ピン（最前面表示） | 常にON / 最新のみON / デフォルトOFF |
| ドラッグ成功時に閉じる | ドラッグ&ドロップ成功時にウィンドウを閉じる |

#### メニューバー

| 設定項目 | 説明 |
|---------|------|
| アイコン | Mas / モノクロ / カメラ / 枠 の 4 種類 |

### ショートカットタブ

各アクションのキーバインドを自由にカスタマイズできます。

| 機能 | デフォルト |
|-----|-----------|
| 全画面キャプチャ | `⌘⇧3` |
| 範囲選択 | `⌘⇧4` |
| キャプチャ枠表示 | `⌘⇧6` |
| GIF録画 | `⌘⇧7` |
| 動画撮影 | `⌘⇧8` |
| ライブラリ | `⌘⇧L` |

- 変更はすぐに反映されます
- 同じキーの重複使用は自動で警告されます
- 「デフォルトに戻す」ボタンで個別リセット、「すべてデフォルトに戻す」で一括リセット

### 開発タブ（開発者モード有効時のみ）

一般タブで「開発者モード」を ON にすると表示されます。

| セクション | 内容 |
|-----------|------|
| データ | アプリデータフォルダの確認・Finderで開く |
| キャプチャ | 自UIをキャプチャに含める（Mas のウィンドウもスクリーンショットに映る） |
| 遅延キャプチャ | 1〜10 秒の遅延後に全画面/範囲選択キャプチャ（テスト用） |

通常、Mas のウィンドウ（エディター、ツールバー、オーバーレイ等）はスクリーンキャプチャから自動的に除外されます。「自UIをキャプチャに含める」を ON にすると、Mas のウィンドウもキャプチャ対象になります（メニューやライブラリなど通常キャプチャしづらい UI 要素を撮影したい場合に使います）。

### 情報タブ

アプリ名、バージョン、説明文、コピーライトを表示します。

## 自動保存と出力

### クリップボード

キャプチャ時に自動でクリップボードにコピーされます（設定で OFF 可能）。編集後も右クリック → コピーで手動コピーできます。

### ファイル保存

- **自動保存**: 設定で指定したフォルダに PNG/JPEG 形式で保存（既定は `~/Pictures/Mas`）
- **手動保存**: `⌘S` または右クリック → 保存でダイアログから保存先を選択
- **ドラッグ&ドロップ**: エディターウィンドウの画像を直接他のアプリにドロップ（右下のドラッグアイコンから）

### ファイル名

自動保存時のファイル名は `Screenshot_YYYY-MM-DD_HH-mm-ss.png` の形式です。

---

## 自動アップデート

設定 → 一般 → アップデートで「自動アップデート」を ON にすると、GitHub Releases から最新版を自動検出・ダウンロード・インストールします。「今すぐ確認」ボタンで手動チェックも可能です。

新バージョンが見つかると自動的にダウンロード・インストールされ、アプリの再起動を促します。
